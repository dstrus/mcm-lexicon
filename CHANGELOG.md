# Changelog

What changed in each release of MCM Lexicon, newest first.

## 0.1.0-beta.1 (2026-11-05)

The first public build: a catalog of every MCM option in a Skyrim mod list, read  at run-time with the game closed, and an editor for MCM Recorder recordings that checks them against what's installed and writes exactly what MCM Recorder reads. Built primarily for Skyrim VR players and list authors, and works with any Skyrim SE or AE setup managed with Mod Organizer 2, or a plain `Data` folder (including Vortex setups).
