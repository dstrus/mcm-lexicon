# Drawings

The app icon and favicon are rendered from these by `make icons`.

The diamond on the game's near-black is a stand-in until a mark is chosen (PLAN.md §9). The mark will be drawn as Hermaeus's is: one shape that survives 16 pixels, used in the top bar in the text color with a cut-out, and as the icon in verdigris on near-black in a rounded square, with a simpler drawing for the 16-pixel size.
